# obstacle-course

A small obstacle-course game project built with Unity and C#. This repository contains the project source and assets.

## Open the project

1. Install Unity Hub and a Unity Editor version compatible with the project files.
2. In Unity Hub, choose **Add** or **Open**, then select this repository folder.
3. Open the project and run the main scene from the Editor.

The project may require assets or editor settings included in the repository. If Unity reports a version mismatch, use the editor version recorded in the project settings where available.
